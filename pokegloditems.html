🔴 포획용 도구 (몬스터볼)

도구명 도구 효과 획득 방법 획득 가능 버전
몬스터볼 야생 포켓몬을 잡는 기본 볼 각 마을 상점 (200원) 공통
슈퍼볼 몬스터볼보다 포획률이 1.5배 높다. 각 마을 상점 (600원) 공통
하이퍼볼 몬스터볼보다 포획률이 2배 높다. 후반부 마을 상점 (1200원) 공통
루어볼 낚싯대로 낚은 포켓몬 포획률 상승 고동마을 강집에게 '파란규토리' 전달 공통
레벨볼 내 포켓몬보다 레벨이 낮을수록 포획률 상승 고동마을 강집에게 '빨간규토리' 전달 공통
문볼 달의돌로 진화하는 포켓몬 포획률 상승 고동마을 강집에게 '노란규토리' 전달 공통
헤비볼 체중이 무거운 포켓몬일수록 포획률 상승 고동마을 강집에게 '검은규토리' 전달 공통
스피드볼 잘 도망가는 포켓몬(전설의 개 등) 포획률 상승 고동마을 강집에게 '하얀규토리' 전달 공통
프렌드볼 잡은 포켓몬의 친밀도가 200이 된다. 고동마을 강집에게 '초록규토리' 전달 공통
러브러브볼 자신의 포켓몬과 성별이 다르고 같은 종류일 때 포획률 상승 고동마을 강집에게 '분홍규토리' 전달 공통

회복약 HP 및 모든 상태이상을 완전히 회복한다. 포켓몬리그 등 후반부 상점 (3000원) 공통

기력의덩어리 기절한 포켓몬을 부활시키고 HP를 모두 회복한다. 필드 획득 (비매품) 공통
튼튼밀크 포켓몬의 HP를 100 회복한다. 39번 도로 틈새의동굴 농장 (500원) 공통
